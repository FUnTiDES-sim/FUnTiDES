# Benchmark Configuration

This folder contains results generated by benchmarking funtides solver on Inria laptop equiped with `Nvidia RTX 1000` and `Intel i7 ULTRA 155H`.

## Folder naming convention

Folder are named after compilers version, without dot and prefixed with compiler initial:

- `c` for Cuda
- `g` for GNU C and C++ compiler
- `k` for Kokkos version

For example `c132g142k51` stands for `Cuda 13.2` with `GCC/G++ 14.2` and `Kokkos 5.1`.

## Benchmark Execution

Benchmarks are launched with bash script `scripts/benchmarks/run_benchmarks_gpu_laptop.sh`. It has to be launched in build folder.

It generates 4 files that are manually copied in right folder.
