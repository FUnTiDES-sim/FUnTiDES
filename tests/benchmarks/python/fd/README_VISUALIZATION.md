# Wavefield Snapshot Visualization

This directory contains tools for visualizing wavefield snapshots generated by the FD solver Python bindings.

## Quick Start

```bash
# Generate snapshots
python3 test_fd_solver_example.py

# View a single snapshot (central vertical plane)
python3 visualize_snapshots.py --snapshot 100

# Create an animation
python3 visualize_snapshots.py --animate --range 0 890 --step 10 --fps 10
```

## Files

- `test_fd_solver_example.py` - Run FD solver and generate snapshots
- `visualize_snapshots.py` - Visualization tool for snapshots
- `snapshots/` - Directory containing wavefield snapshot files (created after running test)

## Visualization Script Usage

### Display Single Snapshot

```bash
# Central vertical plane (XZ at y=center)
python3 visualize_snapshots.py --snapshot 100

# Horizontal plane (XY at z=50)
python3 visualize_snapshots.py --snapshot 100 --slice xy --slice-index 50

# Different vertical plane (YZ at x=80)
python3 visualize_snapshots.py --snapshot 100 --slice yz --slice-index 80

# Save to specific file
python3 visualize_snapshots.py --snapshot 100 --output my_snapshot.png
```

### Display Multiple Snapshots

```bash
# Export range as individual images
python3 visualize_snapshots.py --range 0 500 --step 20

# Export to custom directory
python3 visualize_snapshots.py --range 0 500 --step 20 --output-dir my_images

# Use different slice type
python3 visualize_snapshots.py --range 0 500 --step 20 --slice xy
```

### Create Animation

```bash
# Basic animation (10 fps, all snapshots)
python3 visualize_snapshots.py --animate --range 0 890 --step 10

# Custom frame rate and output
python3 visualize_snapshots.py --animate --range 0 890 --step 10 \
    --fps 15 --output wave_propagation.mp4

# High resolution animation
python3 visualize_snapshots.py --animate --range 0 890 --step 10 \
    --fps 20 --dpi 300 --output high_res_animation.mp4

# Horizontal slice animation
python3 visualize_snapshots.py --animate --range 0 890 --step 10 \
    --slice xy --slice-index 50
```

### Advanced Options

```bash
# Custom color scale
python3 visualize_snapshots.py --snapshot 100 --vmin -1e4 --vmax 1e4

# Different colormap
python3 visualize_snapshots.py --snapshot 100 --cmap RdBu_r

# Specify snapshot directory
python3 visualize_snapshots.py --dir path/to/snapshots --snapshot 100
```

## Slice Types

The visualization script supports three types of 2D slices from the 3D wavefield:

### XZ Slice (Default)
- **Description:** Vertical plane at constant Y
- **Default:** Central plane (y = ny/2)
- **Usage:** `--slice xz --slice-index 100`
- **Best for:** Viewing wave propagation in the vertical direction

### XY Slice
- **Description:** Horizontal plane at constant Z
- **Default:** Central plane (z = nz/2)
- **Usage:** `--slice xy --slice-index 50`
- **Best for:** Viewing wave patterns on horizontal surfaces

### YZ Slice
- **Description:** Vertical plane at constant X
- **Default:** Central plane (x = nx/2)
- **Usage:** `--slice yz --slice-index 80`
- **Best for:** Side view of wave propagation

## Colormap Options

Common colormaps for wavefield visualization:

- `seismic` (default) - Red/white/blue, good for pressure fields
- `RdBu_r` - Reversed red-blue
- `viridis` - Perceptually uniform
- `plasma` - High contrast
- `coolwarm` - Cool/warm diverging

See [Matplotlib Colormaps](https://matplotlib.org/stable/users/explain/colors/colormaps.html) for more options.

## Command Line Arguments

| Argument | Description | Default |
|----------|-------------|---------|
| `--dir DIR` | Snapshot directory | `snapshots` |
| `--snapshot N` | Display snapshot at time step N | - |
| `--range START END` | Process range of time steps | - |
| `--step N` | Step between snapshots | 1 |
| `--slice TYPE` | Slice type (xy, xz, yz) | `xz` |
| `--slice-index N` | Index for slice | Central |
| `--cmap NAME` | Colormap name | `seismic` |
| `--vmin VAL` | Min color scale value | Auto |
| `--vmax VAL` | Max color scale value | Auto |
| `--animate` | Create animation | False |
| `--fps N` | Animation frame rate | 10 |
| `--output FILE` | Output filename | Auto |
| `--output-dir DIR` | Output directory for images | `snapshot_images` |
| `--dpi N` | Resolution (dots per inch) | 150 |

## Tips and Tricks

### Consistent Color Scaling

For animations or comparing multiple snapshots, use consistent color scales:

```bash
# First, find the max value
python3 -c "import numpy as np; from glob import glob
files = sorted(glob('snapshots/*.npy'))
vmax = max(abs(np.load(f)).max() for f in files)
print(f'Use --vmin {-vmax:.2e} --vmax {vmax:.2e}')"

# Then use these values
python3 visualize_snapshots.py --animate --range 0 890 --step 10 \
    --vmin -1.5e4 --vmax 1.5e4
```

### Memory-Efficient Animation

For very large simulations, process in chunks:

```bash
# Process first half
python3 visualize_snapshots.py --animate --range 0 450 --step 10 \
    --output part1.mp4

# Process second half
python3 visualize_snapshots.py --animate --range 450 890 --step 10 \
    --output part2.mp4

# Combine with ffmpeg
ffmpeg -i "concat:part1.mp4|part2.mp4" -c copy full_animation.mp4
```

### Custom Python Analysis

You can also load and analyze snapshots directly in Python:

```python
import numpy as np
import matplotlib.pyplot as plt

# Load snapshot
wavefield = np.load('snapshots/wavefield_000100.npy')

# Compute statistics
print(f"Shape: {wavefield.shape}")
print(f"Min: {wavefield.min():.2e}")
print(f"Max: {wavefield.max():.2e}")
print(f"Mean: {wavefield.mean():.2e}")
print(f"Std: {wavefield.std():.2e}")

# Extract central vertical slice
ny = wavefield.shape[1]
central_slice = wavefield[:, ny//2, :]

# Plot
plt.figure(figsize=(12, 8))
plt.imshow(central_slice.T, cmap='seismic', aspect='auto')
plt.colorbar(label='Pressure')
plt.title('Central Vertical Slice')
plt.xlabel('X index')
plt.ylabel('Z index')
plt.savefig('custom_plot.png', dpi=150)
```

## Troubleshooting

### FFmpeg Not Found

If you get an error about FFmpeg when creating animations:

```bash
# Ubuntu/Debian
sudo apt-get install ffmpeg

# macOS
brew install ffmpeg

# Or create individual images instead
python3 visualize_snapshots.py --range 0 890 --step 10
```

### Out of Memory

For large grids or many snapshots:
- Increase `--step` to process fewer snapshots
- Use lower `--dpi` for smaller file sizes
- Process in smaller ranges

### Incorrect Colors

If the wavefield appears all one color:
- Check the color scale with `--vmin` and `--vmax`
- Verify the snapshot files contain valid data
- Try a different colormap with `--cmap`
