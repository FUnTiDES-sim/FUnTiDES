ROOT CAUSE OF THE BUG:
======================

The bug was in the argument order of basisGradientAt() calls.

Function signature:
  static real_t basisGradientAt(const int q, const int p)
  where:
    q = quadrature point index
    p = basis function index

WRONG (buggy tensorial):
  const real_t gia = basisGradientAt(qa, i);  // qa=point, i=basis

CORRECT (makutu and fixed tensorial):
  const real_t gia = basisGradientAt(i, qa);  // i=basis, qa=point

This caused the tensorial implementation to compute the transpose of the
gradient matrix, completely breaking the stiffness matrix assembly.
